Simulate table script summary

Script:
src/simulate_table.py

Inputs:
- data/processed/matches_features.csv
- models/xgboost_model.joblib

Settings:
- target season: 2024
- simulations: 10000
- points system: win=3, draw=1, loss=0

Output files:
- outputs/simulation_summary.csv
- outputs/simulation_position_probabilities.csv

Saved output sizes:
- simulation_summary.csv rows: 96
- simulation_position_probabilities.csv rows: 1848

Example results:
- Bayern Munich expected position: 1.446
- Bayern Munich league win probability: 0.6520
- Bayer Leverkusen expected position: 2.0324
- Bayer Leverkusen league win probability: 0.3024

Notes:
- Probabilities are generated by the trained XGBoost model.
- Match outcomes are sampled randomly using predicted class probabilities.
- League ranking uses points first and then team name as a simple tie-breaker.
